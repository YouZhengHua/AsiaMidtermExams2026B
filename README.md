# 遊戲引擎應用創作3B 期中考試題目

此專案為 遊戲引擎應用創作3B 的期中考題。

本次考試總共有 3 個題組，共 100 分。

考試時間為 2026/10/29 15:20 ~ 18:00，共計 160 分鐘。

題組是 Content 目錄底下的 QuestionSet_1, QuestionSet_2, QuestionSet_3 三個資料夾。

各題組的評分細節可以參考題組底下的 README.md 文件說明。

每個題組都有前置作業，開始答題前務必先完成前置作業

交卷方式流程如下 :

1. 打開專案資料夾，選擇以下檔案與資料夾，
    - MidtermExams.uproject
    - Config 資料夾
    - Content 資料夾
2. 將三個目標統一壓縮成一個檔案，並將檔名命名為 **{學號}_{底線}.zip** (例如 114200146_游政樺)，請不要將壓縮檔加密。
3. 將壓縮檔上傳至創課的交卷區內。(如果檔案過大無法上傳至創課，請先將檔案上傳至雲端，再將連結分享至創課，請記得開檔案分享，避免無法下載的問題)。

完成交卷後，即可先行離開，如果是使用學校電腦進行考試，離開前請務必將電腦關機。
