# 遊戲引擎應用創作3B 期中考試題目

## 題組一 基礎參數調整與物件擺放 (共 40 分)

### 開始做題前，請務必完成以下動作，確保本題組分數有效

1. 新增一個 Blueprint Class (藍圖類別)，類別不限，不知道用什麼可用 Actor (演員)
2. 將該物件命名為 **{學號}_{姓名}**，舉例: 114200146_游政樺

---

### 題組目標

1. 確保"球"能滾進 BP_EndPoint 內並觸發提示文字 (15分)
2. 確保三個 BP_CheckPoint 都有順利觸發 (15分)
3. 將"球"替換成任意其他顏色，但不能讓其他場景物件的顏色改變 (5分)
4. 確保"球"能碰到 BP_TargetTrack_1 (5分)
