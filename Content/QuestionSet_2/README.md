# 遊戲引擎應用創作3B 期中考試題目

## 題組二 藍圖 與 UI (共 40 分)

### 開始做題前，請務必完成以下動作，確保本題組分數有效

1. 確保 WBP_UI_2 內有包含 **{學號}_{姓名}** 的內容，舉例: 114200146_游政樺

---

### 題組目標

1. 將 WBP_UI_2 內容呈現到畫面中，並且新增畫面按鈕與當前分數顯示文字 (10分)
2. 當按下畫面按鈕時，會生成一顆 BP_Ball_2 (10分)
3. 碰觸到檢查點時，會觸發 OnTouchCheckPoint 事件，並使畫面上的分數文字固定增加 1 點 (10分)
4. 限定 BP_Ball_2 碰觸到終點時，才會觸發 OnEnterEndPoint 事件，並讓分數增加 10 點 (7分)
5. 讓攝影機鎖定場景上的 BP_Ball_2 移動 (3分)
