# 遊戲引擎應用創作3B 期中考試題目

## 題組三 綜合應用 (共 20 分)

### 開始做題前，請務必完成以下動作，確保本題組分數有效

1. 進入遊戲時，會透過 Print String 節點顯示出 「**遊戲開始_{學號}_{姓名}**」，舉例: 遊戲開始_114200146_游政樺

---

### 題組目標

1. 按下 Shoot 按鈕後可以在 BP_Shooter_3 前方生成 BP_Ball_3 (10分)
2. 按下 Shoot 生成的 BP_Ball_3 可以有不同的射擊角度與飛行速度 (5分)
3. 能夠透過 Shoot 按鈕發射出的子彈擊中所有目標 (5分)
